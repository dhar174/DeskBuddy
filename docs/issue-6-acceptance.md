# Issue #6 acceptance evidence

This matrix covers the eight acceptance criteria in [Issue #6](https://github.com/dhar174/DeskBuddy/issues/6). Gate 1 verifies behavior with fakes and authenticated localhost transport. It does not qualify model quality, GPU execution, microphones, cameras, or physical Picoh speech and movement.

| Criterion | Supporting file or test | Verification and result | Limits |
| --- | --- | --- | --- |
| Pytest runs from a clean development install | [`pyproject.toml`](../pyproject.toml), [developer commands](testing.md#gate-1-developer-checks) | Fresh Windows environments: `uv sync --locked --group dev`, `uv lock --check --offline`, and `uv run --no-sync pytest -q`. **380 passed** on each of CPython 3.11.0 and 3.12.2; no optional extras installed. | The locked install can fetch dev and core packages. |
| CI runs automatically on PRs and main pushes | [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) | [Main push run](https://github.com/dhar174/DeskBuddy/actions/runs/43399232346): both jobs passed at baseline `c22b9ab` with 363 tests each. [Disposable PR run](https://github.com/dhar174/DeskBuddy/actions/runs/43487493481): the actual Pytest step failed on the intentional assertion in both jobs (1 failed, 363 passed each). The probe PR was closed and its branch deleted; its commit is outside the implementation history. | The baseline push does not contain #6C. The implementation PR's checks provide the hosted evidence for #6C. |
| CI runs lint, static typing, and tests | [CI steps](../.github/workflows/ci.yml), [tool configuration](../pyproject.toml) | Baseline hosted lint, formatter, mypy, and pytest steps passed on both versions. Locally on each interpreter, `uv run --no-sync ruff check .` passed, `uv run --no-sync ruff format --check src transport tests` reported 41 files formatted, and `uv run --no-sync mypy` found no issues in 14 source files. | Static typing covers the modernized package and transport boundary. Legacy scripts are exercised through contracts. |
| Tests use fakes without models, GPU, hardware, or external credentials | [pytest isolation](../tests/conftest.py), [isolation checks](../tests/test_pytest_isolation.py), [temporary memory tests](../tests/test_legacy_config_contract.py) | Default suite passed with dummy inherited settings and credentials; the isolation tests verify scrubbing, temporary canonical settings, offline flags, blocked runtime imports, and rejection of a non-loopback lookup. `test_question_bank_save_targets_user_data_not_cwd` verifies the temporary write and unchanged checkout sentinel. Authenticated loopback stays enabled. | Python-level controls apply within pytest. Plugin startup, subprocesses, and native I/O have their own boundaries. |
| Contracts cover the main routing outcomes | [Conversation to robot integration](../tests/test_conversation_robot_integration.py), [model selection contracts](../tests/test_conversation_routing_contracts.py) | `uv run --no-sync pytest -q tests/test_conversation_robot_integration.py`: **14 cases** in the full passing suite. Medium local and configured cloud routes, visual/memory/clarification early answers, cloud rewording, empty memory, unavailable vision, missing clarification model, and absent/repeated transcription reach the expected generation or speech behavior. The lost-acknowledgement case observes `ExecutionOutcomeUnknown`, one server reply and one speech call, then continued polling. #6B covers other model selections. | Legacy function bodies run with stubbed GUI/startup. A provider exception escapes before speech; an empty result can reach the robot reply handler and produces no speech. There is no general provider or optional-subsystem exception recovery policy. |
| Named regressions have tests | [Classification contracts](../tests/test_classification_contracts.py), [conversation contracts](../tests/test_conversation_routing_contracts.py) | Full pytest passed, including `test_needs_follow_up_is_deterministic_and_independent_of_dict_identity_or_key_order`, `test_is_requesting_image_matches_image_request_label_in_local_mode`, `test_query_memory_regression_rejects_empty_and_unknown_sentinels_without_inserting`, `test_submit_command_awaits_interpret_and_execute_once_without_coroutine_warnings`, and `test_async_entrypoints_complete_without_unawaited_coroutine_warnings`. | The image-request regression verifies classifier labels; it does not enable or qualify image generation. |
| Optional integration testing is documented and opt-in | [Marker docs](testing.md#optional-integration-tests), [loopback service smoke test](../tests/optional/test_external_robot_service.py) | `uv run --no-sync pytest --collect-only -q tests/optional`: no tests collected (expected exit 5). `uv run --no-sync pytest -q --run-optional=external_service tests/optional`: 1 skipped cleanly with no configured endpoint, on both local interpreters. | Actual service qualification was not run. The guarded test sends only an authenticated connectivity check to an explicitly configured loopback endpoint. |
| Obsolete interactive `test.py` is removed or corrected | [Testing docs](testing.md#offline-contract-tests), [#6A PR](https://github.com/dhar174/DeskBuddy/pull/30) | `git ls-files -- test.py` confirms that the obsolete root script is absent from the tracked tree. Pytest collects from `tests/`. | Separate manual hardware scripts are outside default collection. |

Independent verification review checked the production call path, the lost acknowledgement scenario, isolation, and optional service prerequisites. Its recommendations on canonical temporary paths, preloaded runtimes, and documentation were incorporated.
